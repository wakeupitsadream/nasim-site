# INFRASTRUCTURE — где живёт сайт, кто чем владеет и кто платит

Состояние на 04.11.2026. Факты проверены по первоисточникам (условия Vercel, Neon, Resend, Cloudflare, Anthropic, политика .aeDA). Это не юридическая консультация.

## Коротко для Миши

В России у сайта нет ничего: ни серверов, ни базы, ни домена, ни регистратора. Посетители в Дубае российских блокировок не заметят. Перебои возможны только там, где сервис связан с Россией через владельца аккаунта или способ оплаты, поэтому оплата и домен — на тебе.

1. **Хостинг**: Vercel Inc. (США, право Калифорнии). Серверные функции — во Франкфурте (`fra1`), база Neon — там же (AWS eu-central-1). Страницы раздаются с CDN, ближайшего к посетителю. Дубайский регион Vercel (`dxb1`) с марта 2026 недоступен после аварии AWS в ОАЭ, а у Neon в регионе нет баз вообще, поэтому Франкфурт — правильный выбор, а не компромисс.
2. **Оплата**: российские Visa, Mastercard и Мир эти сервисы не принимают. Платишь ты картой ОАЭ, через роль Billing в команде Vercel.
3. **Домен**: бренд сменился на Brigada (DECISIONS №52), прежняя рекомендация `nasimcare.com` неактуальна. Кандидаты (доступность проверить перед покупкой): `brigadadubai.com` в твоём собственном аккаунте Cloudflare (по себестоимости, около $11 в год, данные владельца скрыты) или `brigada.ae` у аккредитованного регистратора (AEserver, около AED 125 в год, без скрытия данных владельца). Регистрант — ты или твоя компания. Максим получает доступ только к DNS.
4. **AI** (диагностика на сайте, позже AI-перевод в админке) ходит в Claude через российский шлюз Polza AI с оплатой в рублях — аккаунт и ключ Максима, в Vercel как `POLZA_API_KEY` (Preview и Production). Аккаунт Anthropic и ключ от тебя больше не нужны (DECISIONS №51). Без ключа диагностика честно пишет «пока не включена».

## Vercel сейчас: Hobby, временно

С 04.11.2026 проект `nasim-site` работает на Hobby-команде Максима (https://nasim-site.vercel.app) — решение Максима, чтобы показывать результат по ссылке до появления Pro (DECISIONS №19). Это нарушает fair use Vercel для коммерческих сайтов: проект могут ограничить. Пока сайт не принимает реальные заявки и закрыт от индексации, риск принят. До коммерческого запуска — шаги ниже и перенос проекта в Pro-команду (Project Settings → Transfer, без даунтайма и без смены Git-подключения).

## Перевод на Pro (до коммерческого запуска)

1. Максим переводит свою команду на Pro через 14-дневный trial. Без карты trial откатывается на Hobby, и все участники удаляются.
2. Максим приглашает Мишу с ролью **Billing**. Это бесплатно, такая роль у Pro-команды одна.
3. Миша принимает приглашение и привязывает карту ОАЭ: Visa или Mastercard, не предоплаченную, с возможностью списания в USD.
4. Проект `nasim-site` переносится из Hobby-команды (или создаётся заново) из репо `wakeupitsadream/nasim-site`, framework Next.js, Install Command **не переопределять**: при переопределении `pnpm install` Vercel берёт pnpm 6. Регион `fra1` задан в `vercel.json`. Node: в настройках проекта проверить, что выбран 24.x.
5. Neon подключается через Vercel Marketplace в той же команде. Регион Frankfurt (`aws-eu-central-1`), preview-ветки базы **включить до первого PR-деплоя**, иначе превью-сборка будет мигрировать продакшен. Интеграция сама добавит `DATABASE_URL` (pooled) и `DATABASE_URL_UNPOOLED`.
6. Остальные переменные — по `.env.example`.

По fair use Vercel коммерческим считается любой проект, за который кому-то платят, поэтому Hobby — только временный вариант для разработки (см. выше).

## План выхода, если провайдер отключит аккаунт на гражданине РФ

Vercel переносит проект между командами без простоя: деплои, переменные окружения, домены и связь с Git переезжают; интеграции (Neon) и хранилища Blob переносятся отдельно. Миша создаёт свою Pro-команду, Максим становится в ней участником с deploy-местом (+$20/мес), проект переносится. Домен и DNS уже у Миши, поэтому сайт продолжит работать под тем же адресом.

## Домен и DNS

- `.com` — Cloudflare Registrar: продаёт по себестоимости, данные владельца скрыты по умолчанию, перенос к другому регистратору возможен через 60 дней после покупки. Требует NS Cloudflare.
- Альтернатива — Porkbun (~$11.81/год, приватность бесплатно, не блокирует смену регистранта на 60 дней).
- Namecheap и GoDaddy не берём: в прошлом они ограничивали клиентов из РФ.
- `.ae` (по желанию, как редирект на основной домен): `nasim.ae` занят. Любое свободное `name.ae` регистрирует кто угодно без документов, например у AEserver — AED 125 за первый год, около AED 145 за продление, цены без учёта 5% VAT. Скрыть владельца у `.ae` нельзя. `co.ae` — только с лицензией ОАЭ или товарным знаком. Cloudflare и Vercel `.ae` не продают.
- DNS: в Cloudflare, записи на Vercel в режиме **DNS only** (серое облако): A — значение из карточки домена в Vercel, CNAME `www` — на `*.vercel-dns-0xx.com`. MX/TXT для Resend — там же. Прокси Cloudflare перед Vercel не включать: Vercel это не рекомендует. Зона отдельно от хостинга переживает проблемы у Vercel, и сайт можно перенаправить.
- DNSSEC: у Cloudflare включается в один клик, у DNS Vercel не поддерживается.

## Работа из России (разработчик)

На посетителей в Дубае это не влияет — только на работу Максима.

- Дашборды за Cloudflare (Cloudflare, консоль Neon, виджет Turnstile, API Resend) российские провайдеры троттлят: без VPN возможны таймауты. Turnstile, падающий при локальной проверке из РФ, — не баг продукта.
- Кастомные домены на Vercel из РФ иногда не открываются; превью на `*.vercel.app` обычно открываются, но не всегда.
- WhatsApp в РФ заблокирован: проверку `wa.me`-ссылок делает Миша или нужен VPN. Telegram замедлен, но уведомления о заявках уходят Мише в ОАЭ — у него Telegram работает.
- GitHub из РФ в основном доступен.

## Особенности ОАЭ

- Звонки через WhatsApp и Telegram в ОАЭ запрещены, переписка работает. На сайте только «Написать в WhatsApp», звонок — обычный `tel:`.
- В сентябре 2025 провайдеры ОАЭ на две недели заблокировали весь `*.supabase.co` из-за одного чужого проекта. Поэтому сайт и картинки отдаём со своего домена, а не с общих `*.vercel.app` или `*.public.blob.vercel-storage.com`.
- Google Business Profile в ОАЭ поддерживается: выездной сервис оформляется как service-area business, адрес скрыт, до 20 зон обслуживания, кнопка чата WhatsApp.
